## 📂 Proyectos Destacados

### 🎓 **Módulo Educativo PID (CONEIMERA 2025)**
**Reconocimiento: 2º Lugar Nacional**

Sistema interactivo de control PID para barra y bola con Arduino. Incluye:
- Hardware: Arduino + sensores analógicos + actuadores
- Software: Control PID sintonizado + interfaz HMI Nextion
- Documentación técnica completa para educación en automatización

**Tecnologías:** Arduino | MATLAB | Control PID | HMI | Electrónica

---

### 🤖 **Brazo Robótico 3 Grados de Libertad (2024)**

Brazo robótico con control PID cinemático:
- Cinemática directa e inversa con MATLAB
- Control PID para cada articulación
- Simulación en Simulink + implementación en hardware real
- Estructura diseñada en SolidWorks

**Tecnologías:** MATLAB | Simulink | Arduino | Diseño mecánico

---

### 📈 **Sistema de Monitoreo RPM Multi-Motor (2024)**

Sensor de velocidad para banco de bombas múltiples:
- 4 motores independientes monitoreados en tiempo real
- Adquisición de datos con Arduino
- Dashboard de visualización
- Calibración y validación experimental

**Tecnologías:** Arduino | Sensores analógicos | Procesamiento de señales

---

### ☀️ **Solar Tracker con Control PID (2022)**

Sistema de seguimiento solar automático:
- Posicionamiento en dos ejes (azimut y elevación)
- Control PID para minimizar desviación
- Sensores LDR para detección de posición solar
- Aumentó la eficiencia de captación en 35%

**Tecnologías:** Arduino | Motores servo | Control PID | Sensores
